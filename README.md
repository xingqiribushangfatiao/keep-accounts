# 随手记账 MVP

一款专为手机浏览器设计的轻量级记账 Web App,纯 HTML/JS 单文件实现,无需构建步骤,双击 `index.html` 即可使用。

---

## ✨ 功能特性

- 📝 **快速记账** — 数字键盘 + 分类网格 + 备注,3 秒完成一笔记账
- 📊 **首页看板** — 本月支出、今日支出、本月结余、最近记录
- 📋 **消费明细** — 按日期分组,支持月份/分类筛选,左滑删除
- 🥧 **简单统计** — ECharts 环形图展示分类占比,带消费排行
- 💾 **本地存储** — 数据存储在浏览器 localStorage,无服务器
- 🎨 **粉色主题** — 马卡龙色系,12 + 6 个分类 emoji 图标

---

## 🚀 运行方法

### 方法 1:直接打开(最简单)

双击 `index.html`,用浏览器打开即可。

> 推荐浏览器:Chrome 80+、Safari 12+、Edge 80+

### 方法 2:本地服务器(推荐用于手机调试)

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx http-server -p 8000
```

然后浏览器访问 `http://localhost:8000`,或用手机扫码访问。

### 方法 3:Chrome 设备模拟

1. 打开 `index.html`
2. 按 F12 打开 DevTools
3. 点击设备模拟图标(📱)切换到 iPhone 12 Pro 等

## 🎯 核心使用流程

### 1️⃣ 首次打开

- 显示欢迎引导页
- 点击"开始使用"进入首页
- 自动生成 30 天演示数据,可立即体验所有功能

### 2️⃣ 记一笔

1. 首页/明细页点击右下角 **+** 浮动按钮
2. 输入金额(数字键盘) → 选择分类 → 可选填备注
3. 点击"保存",自动返回首页

### 3️⃣ 查看明细

- 底部 Tab 切到"明细"
- 顶部可按月份 / 分类筛选
- **左滑**单条记录可显示删除按钮

### 4️⃣ 查看统计

- 底部 Tab 切到"统计"
- 切换"本周 / 本月 / 本年"查看不同周期
- 环形图 + 排行榜展示分类占比

### 5️⃣ 数据管理

- 设置页 → 数据管理
- **导出数据**:导出 JSON 文件备份
- **重置演示数据**:重新生成 30 天示例
- **清空所有数据**:删除全部记录

---

## ⚠️ 注意事项

1. **数据存储在浏览器本地**,清除浏览器数据 / 切换浏览器 / 隐私模式会丢失
2. **首次加载需要联网**:ECharts 通过 CDN 加载(`https://cdn.jsdelivr.net`),离线时统计页图表会显示"加载失败"
3. **数据规模**:30 天演示数据约 60-90 条,localStorage 5MB 容量足够多年使用
4. **跨域问题**:`file://` 协议下 localStorage 可用,部分浏览器(如 Safari)对 file:// 有限制,推荐用 HTTP 方式
