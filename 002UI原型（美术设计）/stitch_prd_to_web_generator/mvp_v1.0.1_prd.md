### 不在本版本范围（沿用 v1.0 决策）

| 功能 | 状态 | 说明 |
|------|------|------|
| 云同步 | 仍不做 | 后续 v1.2 考虑 |
| 多端同步 | 仍不做 | 数据仅本地 IndexedDB |
| 手机号/邮箱注册 | 仍不做 | 本版本仅支持用户名+密码 |
| 找回密码 | 仍不做 | 本地存储无安全通道，建议用户牢记 |

> 💡 **安全说明**：由于本应用是**纯前端本地应用**（无后端服务器），密码哈希存储在用户本地的 IndexedDB 中。这种方案可以防止他人通过查看源码/缓存直接获取明文密码，但**无法防御能物理访问设备的攻击者**。后续版本若引入云同步，将在后端实现真正的密码校验与加盐策略。

## 1. 产品概述

### 1.1 产品定位
一款专为手机浏览器设计的轻量级记账工具，无需下载安装，打开网页即可使用。聚焦「**快速记账**」和「**简单统计**」两个核心功能。

### 1.2 核心价值
- **即开即用**：手机浏览器访问，无需安装
- **极简操作**：3秒完成一笔记账
- **清晰明了**：钱花在哪，一目了然
- **灵活适配**：个人、家庭、小微企业都能用
- **隐私本地**：v1.0.1 起数据按账号隔离，存储在用户本地

### 1.3 目标用户

| 用户群体 | 典型场景 | 核心需求 |
|---------|---------|---------|
| **个人用户** | 刚工作的年轻人、学生、自由职业者 | 记录日常消费，了解支出习惯 |
| **家庭/情侣** | 夫妻共同记账、家庭开销管理 | 多人共享账本，掌握家庭财务 |
| **小微企业** | 小店主、个体户、工作室 | 简单记录营收，了解盈亏情况 |

### 1.4 使用场景

```
【个人场景】
小王每天记录午餐、交通、购物等消费，月底看看钱花哪了

【家庭场景】
夫妻俩用不同账号在同一台手机上记账，老公看自己的支出，老婆看自己的

【小微场景】
小花经营奶茶店，记录每天原材料采购和营业收入，简单算盈亏
```

> ⚠️ **v1.0.1 说明**：本版本不同账号的数据**互相独立**，同一台设备上需要切换账号才能查看不同用户的数据。真正的「多人共享账本」将在 v1.2 配合云同步实现。

### 3.5 🆕 用户注册登录

#### 3.5.1 注册流程

```
打开网页（未登录）→ 跳转到注册页 → 输入用户名+密码+确认密码
                                              ↓
                                    客户端校验（格式、唯一性）
                                              ↓
                                  生成 salt + SHA-256 哈希
                                              ↓
                                       写入 users 表
                                              ↓
                                  自动登录 → 跳转首页
```

#### 3.5.2 登录流程

```
打开网页（未登录）→ 跳转到登录页 → 输入用户名+密码
                                          ↓
                              校验用户名是否存在
                                          ↓
                       用相同 salt + SHA-256 哈希后比对
                                          ↓
                          匹配 → 创建 session → 跳转首页
                          不匹配 → 提示「用户名或密码错误」
```

#### 3.5.3 退出登录

```
设置页 → 点击「退出登录」→ 二次确认 → 清除 session
                                          ↓
                              跳转登录页（保留本地数据）
```

> 退出登录**不会删除**本地任何数据，只是清空当前会话。下次用相同账号登录即可看到全部历史记录。

#### 3.5.4 字段说明

**注册**

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| 用户名 | String | 是 | 3~20 位，仅支持中英文/字母/数字/下划线 | 注册后不可修改，全设备唯一 |
| 密码 | String | 是 | 6~20 位，至少包含字母和数字 | 客户端 SHA-256 + salt 哈希存储 |
| 确认密码 | String | 是 | 与密码完全一致 | 仅前端校验，不存储 |

**登录**

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| 用户名 | String | 是 | - | - |
| 密码 | String | 是 | - | - |
| 记住我 | Boolean | 否 | 默认关闭 | 开启后 7 天内自动登录 |

#### 3.5.5 数据存储（新增部分）

```javascript
// 用户表（新增）
users: [
  {
    id: 'uuid',                     // 用户唯一ID
    username: 'zhangsan',           // 用户名（唯一）
    passwordHash: 'a1b2c3...',      // SHA-256(密码 + salt)
    salt: 'r8Xk2p...',              // 随机盐值（16字节base64）
    createdAt: 1723423456789,
    lastLoginAt: 1723423456789
  }
],

// 会话表（新增）
session: {
  userId: 'uuid',                   // 当前登录用户ID
  username: 'zhangsan',             // 缓存用户名（避免启动时频繁读取）
  expiresAt: 1724028256789,         // 会话过期时间戳
  rememberMe: true                  // 是否7天免登录
}
```

#### 3.5.8 错误提示规范

| 场景 | 提示文案 | 触发时机 |
|------|----------|----------|
| 用户名为空 | 「请输入用户名」 | 失焦或提交时 |
| 用户名格式错误 | 「用户名为3-20位，支持中英文、字母、数字、下划线」 | 失焦校验 |
| 用户名已存在 | 「该用户名已被注册，请更换」 | 提交校验 |
| 密码为空 | 「请输入密码」 | 失焦或提交时 |
| 密码强度不足 | 「密码需6-20位，且至少包含字母和数字」 | 失焦校验 |
| 两次密码不一致 | 「两次输入的密码不一致」 | 失焦或提交时 |
| 登录-用户不存在 | 「用户名或密码错误」 | 提交时（**不区分**用户不存在/密码错误，防枚举） |
| 登录-密码错误 | 「用户名或密码错误」 | 同上 |
| 网络/存储异常 | 「注册失败，请重试」 | 异常兜底 |

#### 3.5.9 路由守卫

```javascript
// 路由守卫伪代码
router.beforeEach((to, from, next) => {
  const isLoggedIn = authStore.isLoggedIn()
  
  // 白名单（无需登录即可访问）
  const whiteList = ['/login', '/register']
  
  if (whiteList.includes(to.path)) {
    // 已登录用户访问登录/注册页 → 跳首页
    if (isLoggedIn) return next('/')
    return next()
  }
  
  // 其他页面必须登录
  if (!isLoggedIn) return next('/login')
  next()
})
```

#### 3.5.10 安全与隐私设计

| 项目 | 实现方式 |
|------|----------|
| 密码存储 | SHA-256(密码 + salt)，salt 每个用户独立 16 字节随机生成 |
| 哈希算法 | 使用浏览器原生 `crypto.subtle.digest('SHA-256', ...)` |
| 会话过期 | 关闭「记住我」时 sessionStorage（关闭标签页即失效）；开启时 localStorage（7天） |
| 密码明文 | 任何阶段都不落库、不打印、不上报 |
| 数据隔离 | 所有业务查询必须带 `userId` 过滤条件 |
| 设备切换 | 不支持（数据仅存在本地 IndexedDB） |
| 找回密码 | 不支持（本地存储无法安全重置） |

#### 密码哈希实现

```javascript
// src/utils/crypto.js

/**
 * 生成随机盐值（16字节，base64编码）
 */
export function generateSalt() {
  const arr = new Uint8Array(16)
  crypto.getRandomValues(arr)
  return btoa(String.fromCharCode(...arr))
}

/**
 * SHA-256 哈希
 */
export async function sha256(text) {
  const encoder = new TextEncoder()
  const data = encoder.encode(text)
  const buffer = await crypto.subtle.digest('SHA-256', data)
  return Array.from(new Uint8Array(buffer))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('')
}

/**
 * 用 salt 哈希密码
 */
export async function hashPassword(password, salt) {
  return sha256(password + ':' + salt)
}
```
