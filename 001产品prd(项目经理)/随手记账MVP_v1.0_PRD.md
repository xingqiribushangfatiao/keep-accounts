# 随手记账 MVP v1.0 - 产品需求文档

**文档版本**: v1.0  
**创建日期**: 2026-08-12  
**产品阶段**: MVP（最小可行产品）  
**目标平台**: 手机浏览器 Web App  

---

## 1. 产品概述

### 1.1 产品定位
一款专为手机浏览器设计的轻量级记账工具，无需下载安装，打开网页即可使用。聚焦「**快速记账**」和「**简单统计**」两个核心功能。

### 1.2 核心价值
- **即开即用**：手机浏览器访问，无需安装
- **极简操作**：3秒完成一笔记账
- **清晰明了**：钱花在哪，一目了然
- **灵活适配**：个人、家庭、小微企业都能用

### 1.3 目标用户

| 用户群体 | 典型场景 | 核心需求 |
|---------|---------|---------|
| **个人用户** | 刚工作的年轻人、学生、自由职业者 | 记录日常消费，了解支出习惯 |
| **家庭/情侣** | 夫妻共同记账、家庭开销管理 | 多人共享账本，掌握家庭财务 |
| **小微企业** | 小店主、个体户、工作室 | 简单记录营收，了解盈亏情况 |

### 1.4 使用场景

```
【个人场景】
小王每天记录午餐、交通、购物等消费，月底看看钱花哪了

【家庭场景】
夫妻俩共用账本，老公记房贷车贷，老婆记日常开销，月底一起看家庭收支

【小微场景】
小花经营奶茶店，记录每天原材料采购和营业收入，简单算盈亏
```

## 2. MVP 功能范围

### 2.1 功能清单（仅6个核心功能）

| 序号 | 功能模块 | 功能点 | 优先级 | 说明 |
|------|----------|--------|--------|------|
| 1 | **快速记账** | 记录支出/收入 | P0 | 核心功能，必须极简 |
| 2 | **分类管理** | 12个预设分类+自定义 | P0 | 个人/家庭/小微企业都能用 |
| 3 | **首页看板** | 今日/本月消费概览 | P0 | 一眼看清财务状况 |
| 4 | **消费列表** | 按时间展示记录 | P0 | 支持删除 |
| 5 | **简单统计** | 本月分类占比饼图 | P1 | 钱花在哪 |
| 6 | **本地存储** | 数据存在手机本地 | P0 | 使用 LocalStorage/IndexedDB |

### 2.2 明确不做（后续版本考虑）

| 功能 | 不做原因 | 后续版本 |
|------|----------|----------|
| 用户登录/账号系统 | 降低使用门槛 | v1.2 |
| 云同步 | MVP聚焦本地体验 | v1.2 |
| 预算功能 | 增加复杂度 | v1.1 |
| 日历视图 | 使用频率较低 | v1.1 |
| 数据导出 | MVP阶段手动复制即可 | v1.1 |
| 主题切换 | 默认提供一套精美主题 | v2.0 |
| 图片附件 | 增加存储复杂度 | v2.0 |

## 5. 技术方案

### 5.1 技术选型

| 技术 | 选型 | 说明 |
|------|------|------|
| 前端框架 | **Vue 3** + Vite | 轻量、高效、生态成熟 |
| UI组件 | **Vant 4** | 移动端Vue组件库 |
| 状态管理 | **Pinia** | Vue官方推荐 |
| 图表 | **ECharts** | 功能强大，支持按需加载 |
| 存储 | **localForage** | IndexedDB封装，异步API |
| 样式 | **Tailwind CSS** | 原子化CSS，快速开发 |
| PWA | **Vite PWA** | 离线使用、添加到桌面 |

### 5.2 数据存储方案

#### 使用 localForage (IndexedDB)

```javascript
// 存储结构
{
  // 账本信息（MVP只有一个默认账本，预留多账本扩展）
  books: [
    {
      id: 'default',
      name: '我的账本',           // 账本名称（可修改）
      type: 'personal',          // personal | family | business
      currency: 'CNY',
      createdAt: 1723423456789,
      updatedAt: 1723423456789
    }
  ],

  // 消费记录表
  transactions: [
    {
      id: 'uuid',
      bookId: 'default',         // 所属账本（预留多账本）
      type: 'expense',           // expense | income
      amount: 28.50,
      category: 'food',
      date: '2026-08-12',
      note: '公司附近盖浇饭',
      createdAt: 1723423456789
    }
  ],

  // 自定义分类（用户新增的分类）
  customCategories: [
    {
      id: 'uuid',
      bookId: 'default',         // 所属账本
      name: '宠物',
      icon: '🐱',
      type: 'expense'
    }
  ],

  // 用户设置
  settings: {
    firstVisit: false,           // 是否首次访问
    currentBookId: 'default',    // 当前选中的账本
    currency: 'CNY',             // 货币单位
    theme: 'light'               // 主题（预留）
  }
}
```

> 💡 **设计说明**：MVP版本虽然只有一个本地账本，但数据模型预留了 `bookId` 字段，方便后续版本支持多账本（个人账本、家庭账本、店铺账本）时平滑升级。
