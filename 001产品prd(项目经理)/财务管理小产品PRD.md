## 1. 产品概述

### 1.1 产品名称
**随手记账** - 个人日常消费管理工具

### 1.2 产品定位
一款轻量级、易用的个人财务管理工具，帮助用户记录每日消费，了解自己的消费习惯，实现理性消费和储蓄目标。

### 1.3 产品愿景
让每个人都能轻松管理自己的财务，养成健康的消费习惯，实现财务自由的第一步。

### 1.4 核心价值
- **简单易用**：3秒完成记账，零学习成本
- **数据清晰**：可视化展示消费趋势和结构
- **洞察消费**：智能分析消费习惯，提供节省建议

---

## 2. 目标用户

### 2.1 主要用户画像

| 用户类型 | 特征描述 | 核心需求 |
|---------|---------|---------|
| 职场新人 | 22-28岁，刚参加工作，收入有限 | 控制支出，避免月光 |
| 理财小白 | 想理财但不知从何开始 | 了解钱花在哪里，建立记账习惯 |
| 存钱达人 | 有明确储蓄目标 | 追踪预算执行情况 |
| 学生群体 | 生活费有限，需要精打细算 | 管理有限的资金 |

### 2.2 用户痛点
1. 不知道每月钱花在哪里
2. 记账太麻烦，难以坚持
3. 没有预算概念，经常超支
4. 消费数据分散，难以统计

## 4. 功能详细设计

### 4.1 📝 记账模块

#### 4.1.1 快速记账
**功能描述**: 最核心的功能，让用户快速记录一笔消费

**交互流程**:
1. 点击首页"+"按钮或底部记账按钮
2. 弹出记账弹窗/页面
3. 输入金额（数字键盘）
4. 选择消费分类
5. 选择消费日期（默认今天）
6. 添加备注（可选）
7. 保存

**字段说明**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 金额 | Number | 是 | 支持小数点后2位，单位：元 |
| 分类 | String | 是 | 预设分类 + 自定义分类 |
| 日期 | Date | 是 | 默认当天，可修改 |
| 备注 | String | 否 | 最多100字 |
| 图片 | File | 否 | 小票或商品照片 |

**预设分类**:

| 大类 | 子分类 | 图标 |
|------|--------|------|
| 餐饮 | 早餐、午餐、晚餐、零食、饮料 | 🍔 |
| 交通 | 公交地铁、打车、加油、停车 | 🚗 |
| 购物 | 服饰、美妆、电子产品、日用品 | 🛍️ |
| 居住 | 房租、水电、物业、宽带 | 🏠 |
| 娱乐 | 电影、游戏、旅游、运动 | 🎮 |
| 学习 | 书籍、课程、培训、考试 | 📚 |
| 医疗 | 药品、体检、诊疗 | 💊 |
| 人情 | 礼物、红包、请客 | 🎁 |
| 其他 | 自定义 | 📦 |

#### 4.1.2 收入记录
**功能描述**: 记录收入来源

**预设收入分类**:
- 工资 💰
- 奖金 🏆
- 兼职 💼
- 理财收益 📈
- 红包 🧧
- 其他 📥

### 4.2 📊 统计模块

#### 4.2.1 消费总览
**功能描述**: 展示整体财务状况

**展示内容**:
- 本月支出总额
- 本月收入总额
- 本月结余
- 日均消费
- 与上月对比（环比）

#### 4.2.2 分类统计
**功能描述**: 按分类查看消费分布

**展示形式**:
- 饼图/环形图：展示各类别占比
- 列表：分类名称 + 金额 + 占比 + 笔数
- 点击可查看该分类下的详细记录

#### 4.2.3 趋势分析
**功能描述**: 展示消费趋势变化

**展示形式**:
- 折线图：近7天/30天/12个月消费趋势
- 柱状图：收入 vs 支出对比
- 支持切换时间维度

### 4.3 🎯 预算模块

#### 4.3.1 月度预算设置
**功能描述**: 设置每月总预算和分类预算

**功能点**:
- 设置月度总预算
- 设置分类预算（可选）
- 预算周期：自然月
- 预算可结转设置

#### 4.3.2 预算提醒
**功能描述**: 预算超支预警

**提醒规则**:
- 支出达到预算50%：轻度提醒
- 支出达到预算80%：中度提醒
- 支出达到预算100%：重度提醒
- 分类预算超支提醒

**提醒方式**:
- App内消息
- 推送通知（可选）
- 首页预算进度条变红

### 4.4 📅 记录模块

#### 4.4.1 消费列表
**功能描述**: 查看所有消费记录

**功能点**:
- 按时间倒序排列
- 按月份筛选
- 按分类筛选
- 按金额范围筛选
- 搜索（支持备注内容搜索）
- 左滑编辑/删除

**列表项展示**:
```
[图标] 分类名称        -¥28.00
备注内容              今天 12:30
```

#### 4.4.2 日历视图
**功能描述**: 以日历形式查看消费

**展示内容**:
- 日历上标记有消费的日期
- 日期下方显示当日总支出
- 点击日期查看当日明细

### 4.5 ⚙️ 设置模块

#### 4.5.1 账户管理
- 设置用户名/头像
- 修改密码
- 退出登录

#### 4.5.2 数据管理
- 数据导出（Excel/CSV格式）
- 数据备份到云端
- 数据恢复
- 清空数据

#### 4.5.3 个性化设置
- 主题切换（浅色/深色）
- 货币单位设置
- 周起始日设置
- 每日记账提醒时间

## 5. 用户流程设计

### 5.1 首次使用流程

```
启动App → 欢迎页 → 引导页（展示核心功能）
    ↓
选择记账方式（极简/完整）
    ↓
设置月度预算（可跳过）
    ↓
进入首页 → 完成第一笔记账
```

### 5.2 日常记账流程

```
首页 → 点击"+" → 输入金额 → 选择分类
    ↓
选择日期 → 添加备注（可选）→ 保存
    ↓
返回首页，查看今日/本月统计
```

### 5.3 查看统计流程

```
首页 → 点击统计Tab → 切换时间维度
    ↓
查看饼图/趋势图 → 点击分类查看详情
```

## 7. 界面设计规范

### 7.1 设计原则
- **简洁优先**：界面干净，重点突出
- **一致性**：统一的设计语言
- **反馈及时**：操作后有明确反馈
- **无障碍**：字体大小可调，支持屏幕阅读器

### 7.2 色彩规范

#### 主色调
- 主色：`#2E7D32` (绿色 - 代表财富增长)
- 辅助色：`#FF6B6B` (红色 - 支出)
- 点缀色：`#4ECDC4` (青色 - 收入)

#### 功能色
- 成功：`#4CAF50`
- 警告：`#FFC107`
- 错误：`#F44336`
- 信息：`#2196F3`

#### 中性色
- 背景：`#F5F5F5`
- 卡片：`#FFFFFF`
- 分割线：`#E0E0E0`
- 主文字：`#212121`
- 次文字：`#757575`

### 7.3 字体规范
- 标题：18-24px，Medium
- 正文：14-16px，Regular
- 辅助文字：12px，Regular
- 数字金额：使用等宽字体或 tabular nums

### 7.4 图标规范
- 分类图标：24x24px
- Tab图标：24x24px
- 操作图标：20x20px
- 风格：线性图标，统一描边粗细

## 9. 非功能需求

### 9.1 性能需求
- 启动时间：< 2秒
- 记账操作：< 1秒完成
- 页面切换：< 500ms
- 数据加载：< 3秒（本地数据）
- 支持数据量：单机支持5年以上记账数据流畅运行

### 9.2 安全需求
- 数据本地存储加密（可选）
- 支持指纹/面容ID解锁（可选）
- 数据导出需要验证
- 云端数据同步加密传输

### 9.3 兼容性需求
- **移动端**:
  - iOS 13+
  - Android 8.0+
- **响应式**: 适配手机、平板
- **PWA**: 支持离线使用、可添加到桌面

### 9.4 本地化需求
- 中文简体（默认）
- 中文繁体
- 英文
- 货币单位可配置

## 10. 技术架构建议

### 10.1 技术选型（Web App）
- **前端框架**: React / Vue 3
- **状态管理**: Pinia / Zustand
- **UI组件库**: Ant Design Mobile / Vant
- **图表库**: ECharts / Chart.js
- **本地存储**: IndexedDB (Dexie.js)
- **PWA**: Workbox

### 10.2 数据存储方案
- **本地优先**: IndexedDB 存储所有数据
- **云端同步**: 可选的云同步功能（WebDAV/自建服务）
- **数据导出**: JSON/CSV格式

### 10.3 项目结构
